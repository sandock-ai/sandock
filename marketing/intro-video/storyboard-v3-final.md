### 场景 6: 怎么用 - 代码演示 (1:00-1:16)
**"3 行代码 - 创建 + 挂载 + 执行"**

**录屏内容 - 代码演示**:

```typescript
import { createSandockClient } from 'sandock'

const client = createSandockClient({
  baseUrl: 'https://sandock.ai',
  headers: { 'Authorization': 'Bearer YOUR_API_KEY' }
})

// 1. 获取或创建 Volume
const volume = await client.volume.getByName('my-data', true)

// 2. 创建沙箱并挂载 Volume
const sandbox = await client.sandbox.create({
  image: 'node:24.18.0-alpine',
  volumes: [{
    volumeId: volume.data.id,
    mountPath: '/data'
  }]
})

// 3. 执行代码并保存数据
await client.sandbox.shell(sandbox.data.id, {
  cmd: 'echo "Hello Sandock" > /data/hello.txt && cat /data/hello.txt'
})

// 数据已持久化到 Volume！
console.log('✓ Data persisted to volume')
```

**录制要点**:
- 代码逐行出现或快速输入
- 高亮关键部分：
  - `volume.getByName()` - 获取 Volume
  - `volumes: [...]` - 挂载
  - `> /data/hello.txt` - 保存数据
- 运行后显示成功消息
- 字体大（18-20px），清晰可读

**分段录制（16秒）**:

**0:00-0:05 (5秒)**: 创建 Volume
```typescript
// 1. Create or get volume
const volume = await client.volume.getByName('my-data', true)
```
- 高亮 `getByName('my-data', true)`
- 显示返回: `{ id: 'vol_xxx', name: 'my-data' }`

**0:05-0:10 (5秒)**: 创建沙箱并挂载 Volume
```typescript
// 2. Create sandbox and mount volume
const sandbox = await client.sandbox.create({
  image: 'node:24.18.0-alpine',
  volumes: [{ volumeId: volume.data.id, mountPath: '/data' }]
})
```
- 高亮 `volumes: [...]` 和 `mountPath: '/data'`
- 显示返回: `{ id: 'sb_xxx' }`

**0:10-0:16 (6秒)**: 执行代码
```typescript
// 3. Execute code with volume access

  cmd: 'echo "Hello Sandock" > /data/hello.txt && cat /data/hello.txt'
})
```
- 高亮 `> /data/hello.txt`
- 显示输出: `Hello Sandock` + `✓ Success`
